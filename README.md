# Solara Café — Website Demo

Solara Café is a fictional café and brunch concept created by **Glanzberg Web** as a portfolio demonstration.

This demo shows how a hospitality website can combine strong visual storytelling, menu highlights, hours, atmosphere, and clear visit/reservation calls to action in a polished mobile-first experience.

## Demo highlights

- Responsive café / restaurant landing page
- Warm editorial visual direction
- Featured menu items
- Hours and location section
- Reservation-request form demonstration
- Mobile navigation
- Static structure ready for GitHub Pages

## Important

Solara Café is not a real business. Names, menu items, prices, testimonials, phone numbers, hours, address details, and other business information are sample content used solely for demonstration.

The reservation form is intentionally configured as a demo and does not send information to a real restaurant.
